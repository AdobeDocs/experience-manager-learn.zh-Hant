# 使用範本建立IC檔案

使用預先定義的範本和可重複使用的片段，建立互動式通訊檔案。 這可確保檔案建立的一致性和效率。 選取正確的表單資料模型(FDM)並將片段插入指定的目標區域，以內嵌動態資料。 測試最終輸出的精確度和格式。
