# 將AEM Forms與Adobe Experience Platform(AEP)整合

>[!NOTE]
>
>將Adaptive Forms (AEM Forms)與Adobe Experience Platform (AEP)連線的功能屬於搶先存取計畫。請將您工作地址的電子郵件傳送至aem-forms-ea@adobe.com以請求存取權。

您可以將AEM Forms與Adobe Experience Platform連線起來，轉換您的表單體驗。 這項強大的整合可讓組織運用即時客戶設定檔來提供個人化表單體驗、簡化將AEM Forms資料提交至Experience Platform的程式，以及在Adobe生態系統中建立統一的客戶記錄。

本教學課程將逐步帶您瞭解建立AEM Forms與AEP整合的步驟
